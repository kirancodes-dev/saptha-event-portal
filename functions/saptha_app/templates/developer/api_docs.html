Developer API Reference

Welcome to the SapthaEvent REST API Sandbox. Here you can explore documentation for all platform routes, interact with the actual endpoints, and generate client boilerplate codes automatically.

All requests must include the CSRF header token for browser authentication when using session cookies. For stateless API clients, supply the Bearer JWT token.

Authentication Protocol

Authenticating with the API requires issuing a POST login command. The returned credentials contains an access_token which must be included inside the Authorization: Bearer <Token> header on all secure routes.

POST /api/v1/auth/login

User Login

Generates a JWT access and refresh token using user email and password.

Try It Out
Client Boilerplate
curl -X POST http://127.0.0.1:5001/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@sapthaevent.com", "password":"Admin@123"}'
fetch('http://127.0.0.1:5001/api/v1/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'admin@sapthaevent.com',
    password: 'Admin@123'
  })
}).then(r => r.json()).then(console.log);
import requests

res = requests.post(
    "http://127.0.0.1:5001/api/v1/auth/login",
    json={"email": "admin@sapthaevent.com", "password": "Admin@123"}
)
print(res.json())

GET /api/v1/auth/me

Get Profile Details

Returns payload validation parameters of the currently authenticated user.

Try It Out

Secure route. Insert Bearer Token inside the header box above before sending.

Client Boilerplate
curl http://127.0.0.1:5001/api/v1/auth/me \
  -H "Authorization: Bearer <TOKEN>"
fetch('http://127.0.0.1:5001/api/v1/auth/me', {
  headers: { 'Authorization': 'Bearer ' }
}).then(r => r.json()).then(console.log);
import requests

res = requests.get(
    "http://127.0.0.1:5001/api/v1/auth/me",
    headers={"Authorization": "Bearer "}
)
print(res.json())

GET /api/v1/events

List All Events

Returns list of registered active university events with pagination support.

Try It Out
Client Boilerplate
curl http://127.0.0.1:5001/api/v1/events?limit=10
fetch('http://127.0.0.1:5001/api/v1/events?limit=10')
  .then(r => r.json()).then(console.log);
import requests

res = requests.get("http://127.0.0.1:5001/api/v1/events", params={"limit": 10})
print(res.json())
